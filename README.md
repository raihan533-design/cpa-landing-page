# 🚀 Universal High-Converting CPA Marketing Landing Page

একটি আধুনিক, মোবাইল-রেসপন্সিভ এবং হাই-কনভার্টিং CPA মার্কেটিং ল্যান্ডিং পেজ—যাতে রয়েছে অ্যাডমিন প্যানেল, লাইভ প্রিভিউ, ১-ক্লিক ইমেজ প্রিসেট এবং ভার্সেল (Vercel) ডিপ্লয়মেন্ট সাপোর্ট।

---

## 📁 ফাইল স্ট্রাকচার

- **`index.html`**: ভিজিটরদের জন্য মূল হাই-কনভার্টিং ল্যান্ডিং পেজ (আই-ক্যাচিং ইমেজ, পালসিং ক্লেইম বাটন, কাউন্টডাউন টাইমার, লাইভ উইনার পপআপ এবং স্টেপ গাইড)।
- **`admin.html`**: অ্যাডমিন কন্ট্রোল প্যানেল (পাসওয়ার্ড প্রোটেক্টেড: ডিফল্ট পাসকোড `admin`), যেখান থেকে ইমেজ, অফার টাইটেল, বাটন টেক্সট ও CPA অ্যাফিলিয়েট লিংক লাইভ পরিবর্তন করা যায়।
- **`config.json`**: ডিফল্ট কনফিগারেশন ফাইল।
- **`vercel.json`**: ভার্সেলে ডিপ্লয় করার জন্য কনফিগারেশন।
- **`server.js`**: লোকাল কম্পিউটারে রান ও টেস্ট করার জন্য জিরো-ডিপেনডেন্সি নোড সার্ভার।

## 🌐 ভার্সেলে (Vercel) ফ্রি ডিপ্লয় করার নিয়ম

### পদ্ধতি ১: GitHub + Vercel (সবচেয়ে সহজ ও জনপ্রিয়)
1. [GitHub.com](https://github.com)-এ একটি নতুন রিপোজিটরি (Repository) তৈরি করুন।
2. এই ফোল্ডারের ফাইলগুলো গিটহাবে আপলোড করুন।
3. [Vercel.com](https://vercel.com)-এ লগইন করে **"Add New Project"** -> **"Import"**-এ ক্লিক করে আপনার গিটহাব রিপোজিটরিটি সিলেক্ট করুন।
4. **Deploy** বাটনে চাপ দিন। ১০ সেকেন্ডের মধ্যে আপনার লাইভ লিংক (যেমন: `https://your-cpa-page.vercel.app`) তৈরি হয়ে যাবে!

### পদ্ধতি ২: Vercel CLI দিয়ে সরাসরি টার্মিনাল থেকে
টার্মিনালে লিখুন:
```bash
npx vercel
```
- এটি প্রথমবার আপনার ইমেইল বা গিটহাব দিয়ে লগইন করতে বলবে।
- এরপর `Y` প্রেস করলেই কয়েক সেকেন্ডে সাইট লাইভ হয়ে যাবে!
